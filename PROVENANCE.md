# Provenance and attribution

This private archive was assembled from the owner's recovered `proj2a` and `proj2b` directories for UC Berkeley CS 61B, Fall 2024. It preserves those two module boundaries; duplicate Java package names are not merged.

Course specifications:

- [Project 2A: Ngordnet (NGrams)](https://fa24.datastructur.es/projects/proj2a/).
- [Project 2B: Ngordnet (Wordnet)](https://fa24.datastructur.es/projects/proj2b/).
- [Fall 2024 skeleton repository](https://github.com/Berkeley-CS61B/skeleton-fa24).

The archive includes supplied browser and plotting infrastructure, example/demo files, and original tests, alongside the recovered data-structure and query implementations. Comments attributing code or tests to Josh Hug and other existing notices were retained. No claim is made that the entire application, interface, dataset, or scaffolding was independently authored by the archive owner. The small data fixtures came from the local course distribution and retain their original contents.

Both `static/jquery.min.js` files retain their original jQuery 3.1.0 copyright/license header. External course-library JARs are not bundled or relicensed; their notices and licenses remain with the library distribution. No top-level license file was present in the two recovered project directories or their course-repository root, and no new blanket license was added here.

Archive preparation excluded Git history, IDE settings, compiled classes, output directories, operating-system metadata, large dataset files, and ZIP backups. Only `proj2b/src/main/Main.java` was changed among the copied application sources: the existing real hyponym handler is registered in place of unused dummy history routes, small matching fixtures are selected by default, and optional input paths are accepted. New scripts, smoke checks, and documentation are archive-maintenance additions; original algorithms were not rewritten.

This package is intended for a private repository and private review. Retaining attribution is not permission to publish course solutions or redistribute upstream materials beyond their applicable terms.
